# Third-party code

`src/input.rs` adapts the text-input example from Zed's GPUI framework at
commit `e5bdd01cd819d6348ae764e69218adfee3d7edab`:
https://github.com/zed-industries/zed/blob/e5bdd01cd819d6348ae764e69218adfee3d7edab/crates/gpui/examples/input.rs

The example belongs to the Zed GPUI crate and is licensed under Apache-2.0.
The license is retained in `licenses/GPUI-APACHE-2.0.txt`.

The launcher does not load the extracted macOS program or its bundled assets.
